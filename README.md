# 部落冲突 · Clash Village

一个纯前端实现的《部落冲突》类单机游戏：建设村庄、采集资源、训练部队、进攻掠夺，全部经典玩法循环都有，并做了时间加速让节奏更爽快。

## 怎么玩

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开。

**方式二（本地服务器）**：

```bash
python -m http.server 8277
```

然后访问 http://localhost:8277

存档自动保存在浏览器 localStorage 里，关掉页面进度不会丢，采集器离线也会继续产出（最多累计 8 小时）。

## 玩法说明

### 村庄经营
- **点击建筑** 查看属性、升级；**按住选中的建筑拖动** 可以重新摆放
- **金矿 / 圣水收集器** 会随时间产出，头上冒图标时点击收集
- **建筑工人**（👷）数量限制同时进行的建造数，宝石可以买更多小屋（最多 5 个）
- **大本营** 是核心：升级它解锁更多建筑和数量上限（1~8 级）
- 地图上会长出 **障碍物**（树、石头），花点资源清理有机会获得宝石；运气好会刷出必出大量宝石的 **宝石箱**
- 城墙购买后可 **连续放置**，还支持一键升级全部同级城墙

### 军事
- **兵营** 训练部队（等级解锁兵种），多个兵营会加快训练速度
- **军营** 决定部队人口上限
- **实验室** 研究强化兵种和法术等级
- **法术工厂** 酿造雷电 / 治疗 / 狂暴法术

10 个兵种：野蛮人、弓箭手、哥布林（偷资源×2）、巨人（抗伤优先打防御）、炸弹人（对墙 40 倍伤害自爆）、气球兵（飞越城墙）、法师（范围输出）、天使（治疗）、飞龙、皮卡超人。

### 进攻
- 点 **进攻** 花金币搜索对手（可以花钱换下一个），看好战利品再开打
- 点下方卡片选兵种，再点敌方地图空地部署（红色区域禁止部署）
- 星级规则与原作一致：摧毁 50% 一星、炸掉大本营一星、100% 三星
- 3 分钟时限，赢了拿奖杯和战利品，输了掉奖杯
- 敌方村庄按你的大本等级与奖杯数动态生成，防御 AI 齐全：加农炮、箭塔、迫击炮（范围溅射但打不到近身）、法师塔（溅射）、防空火箭

### 小技巧
- 巨人抗伤 + 炸弹人开墙 + 弓箭手法师输出，是经典开局组合
- 迫击炮怕近身、防空火箭打不了地面，找准弱点下兵
- 哥布林打资源建筑双倍伤害，抢钱专用
- 宝石别乱花，优先买第 3 个建筑工人

## 技术

纯 HTML5 Canvas + 原生 JavaScript，零依赖零构建：

```
index.html        入口
css/style.css     界面样式
js/data.js        数值配置(建筑/兵种/法术平衡表)
js/sfx.js         WebAudio 合成音效
js/state.js       游戏状态/存档/经济系统
js/enemy.js       敌方村庄程序化生成
js/battle.js      战斗引擎(A*寻路/部队AI/防御AI/法术)
js/render.js      等距(isometric)渲染器
js/ui.js          界面面板
js/main.js        主循环与输入(拖动/缩放/触屏)
```
