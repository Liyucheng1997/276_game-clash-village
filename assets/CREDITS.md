# 素材来源

建筑各等级、兵种头像、法术卡片、资源图标、树木、字体与丛林场景音乐来自 [ClashKing Assets](https://github.com/ClashKingInc/ClashKingAssets)，通过其公开 CDN https://assets.clashk.ing/ 下载。

每个文件的来源 URL、大小和 SHA-256 见 `manifest.json`。下载脚本为 `tools/fetch-assets.py`。ClashKing 项目采用 GPL-3.0；其许可副本保存为 `CLASHKING-LICENSE.txt`。游戏美术和声音的原始权利属于 Supercell，仓库软件许可证不意味着获得原始游戏素材的独立商业授权。

本项目为非官方本地同人演示，与 Supercell 无关联，也未经其赞助或认可。

草地、海岸、森林排布、场景投影、战斗单位绘制和音效合成为本项目实现。背景音乐为 Jungle Scenery 的 `music.ogg`，并非经典村庄默认音乐。兵种图片是 UI 头像，不是战斗逐帧动画。
